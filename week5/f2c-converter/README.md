# F2C Converter

Simple Fahrenheit to Centigrade converter using Express.

Running locally

1. Install dependencies:

```bash
npm install
```

2. Start server:

```bash
npm start
```

3. Open in browser:

http://localhost:3000/f2c

Notes for CodeSandbox

- Import this folder into CodeSandbox (Node template) or create a new sandbox and upload the files.
- Ensure `package.json` is used by the sandbox and use the `start` script to run the server.
